# The reference build

⚠️ **THIS IS NOT SHIPPED CODE AND MUST NOT BE IMPORTED.** It is the prototype the
numbers in [UI.md](../UI.md) §4 and §5 were measured from — plain HTML and CSS,
no framework, no build. It exists so those numbers can be re-derived rather than
trusted, and so the next person can see the target before writing a component.

```
node build.mjs        # writes out.html — two screens, both hero variants
```

The values in UI.md are authoritative. When this and the document disagree, the
document is right and this is stale — it is a photograph, not a source.
